Роман

Связист, программист

О специалисте

Роман - специалист, объединяющий в себе глубокие знания в области связи и программирования. Его экспертиза позволяет создавать эффективные программные решения для диспетчерских служб и систем связи.

Специализация

  • Разработка ПО

    Создание специализированного программного обеспечения для диспетчерских служб и систем связи.

  • Базы данных

    Проектирование и оптимизация баз данных для систем мониторинга и управления.

  • Сетевые решения

    Настройка и программирование сетевого оборудования, включая Mikrotik.

  • Системная интеграция

    Интеграция программных решений с существующими системами связи.

Опыт работы

  • Разработка электронного журнала для диспетчерских служб
  • Создание веб-приложений для лифтовых компаний
  • Программирование и настройка сетевого оборудования
  • Интеграция программных решений с системами связи

Ключевые проекты

  • Электронный журнал диспетчера с системой отчетности
  • Веб-портал для управления лифтовым хозяйством
  • Система мониторинга состояния оборудования
  • Автоматизация процессов диспетчерской службы

Технологический стек

  • Python для разработки десктопных приложений
  • Базы данных (MySQL, MariaDB)
  • Сетевые технологии и протоколы
  • Web-технологии (HTML, CSS, JavaScript)
