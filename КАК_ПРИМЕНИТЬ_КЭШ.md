## Как это работает

### Первый раз (кэша нет):
1. Пользователь заходит на страницу
2. Выполняется SQL запрос к БД
3. Результат сохраняется в файл `cache/yearly_Москва_data9_2024.json`
4. Результат показывается пользователю

### Второй раз (кэш есть):
1. Пользователь заходит на страницу
2. Смотрим текущий месяц - март
3. Данные за январь и февраль берутся из кэша (БЫСТРО!)
4. Только март считается заново (так как может меняться)
5. Результат показывается пользователю

### Новый месяц (апрель):
1. Пользователь заходит 1 апреля
2. Март теперь закончен - добавляется в кэш
3. Январь, февраль, март - из кэша
4. Только апрель считается заново

## Настройки

### Интервал обновления текущего месяца
В файле `yearly_stats_cache.py` найдите строку:
```python
if datetime.now() - last_update_time > timedelta(minutes=30):
```

Измените `30` на нужное количество минут:
- `15` - обновлять каждые 15 минут
- `60` - обновлять каждый час
- `5` - обновлять каждые 5 минут

### Очистка кэша вручную

```python
# В Python консоли или добавьте роут:
from yearly_stats_cache import yearly_cache

# Очистить для конкретного города
yearly_cache.invalidate(town='Москва', data_type='data9')

# Очистить весь кэш за текущий год
yearly_cache.invalidate()

# Или просто удалите папку cache
```

### Просмотр кэша

Кэш хранится в папке `cache/` в JSON формате. Можно открыть и посмотреть:
```bash
cat cache/yearly_Москва_data9_2024.json
```
